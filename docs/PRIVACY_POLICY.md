# Privacy Policy — Moin Routine

Effective date: 2026-08-03. Contact: support@example.com. Website: https://example.com/moin-routine

Moin Routine stores routine activities, schedules, completion history, alarm preferences, fasting ranges, cached prayer times, selected location and backups locally on the user's device. If Firebase is configured, Firebase Authentication and Firestore process email address, display name, email-verification state, role, account/subscription status, login timestamps, prayer-routine preference, deletion requests and a limited location summary. Administrators can view and change account/subscription status; privileged changes are audited.

Foreground location is requested only when the user chooses Detect My Location. Continuous/background location is not requested. Google Places/Maps may receive search text, selected place identity, coordinates, IP/device request metadata and standard service telemetry under Google's terms. Google is not used as the prayer-time provider; prayer times are calculated locally.

Android notifications, exact alarms, vibration and lock-screen alarm presentation are used only for user-configured routine reminders. JSON backup files are created or restored only on user request and may contain the local data described above; they exclude passwords, Firebase tokens and administrative secrets. Users control where exported files are stored or shared.

Users may delete local data in the app, request account deletion, or contact support. Local deletion does not automatically delete a Firebase account; an account deletion request is reviewed and processed with associated cloud profile data according to legal and operational retention requirements. Security logs and admin audit records may be retained where required. Data is not sold.
