# Moin Routine — Product Roadmap

## Complete
- Responsive daily habit tracker
- Activity scheduling and management
- Monthly and per-activity progress
- Dashboard analytics, streaks, heatmap and rankings
- Dark/light mode and accent themes
- 3D/glass responsive UI
- Bottom app navigation
- Instant completion statistics
- Offline-first storage and JSON backup/restore
- Installable PWA shell
- Local prayer-time profile support

## Good future additions
- Optional cloud sync across devices
- Browser push notifications through a hosted notification service
- Habit groups/tags and goal templates
- Notes/journal entries per day
- Weekly review cards and personal bests
- Shareable progress summary images
